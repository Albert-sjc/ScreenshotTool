# ScreenshotTool 第一版规格

Status: ready-for-agent

Confirmed: 2026-11-13，用户整体确认需求、默认交互和技术路线。

## Problem Statement

用户需要一款可安装到其他 Windows 电脑的截图工具：可以自定义全局快捷键，像 QQ 截图一样选区和标注，并在完成后把图片贴在桌面最前面作为参考资料。贴图应能在本次运行期间继续修改标注，导出图片则保持普通图片格式。

## Solution

开发一款简体中文、单实例、常驻托盘的 Windows 桌面应用。默认按 Ctrl+Alt+S 开始截图，冻结桌面并隐藏已有贴图，支持手动框选、自动窗口选取和鼠标所在显示器的全屏截图。用户编辑后按完成动作复制、贴图或同时执行两者，也可主动保存为 PNG/JPG。

所有截图内容与标注仅供当前会话及仍打开的贴图使用；关闭不保留历史，重启不恢复。用户主动导出的文件保留。提供携带运行时、仅为当前用户安装的离线安装包。

## User Stories

1. As a Windows 用户, I want 从托盘开始截图或修改设置, so that 软件可以在后台随时使用。
2. As a Windows 用户, I want 自定义截图快捷键并立即生效, so that 不必适应固定按键。
3. As a Windows 用户, I want 检测快捷键占用并保留旧的可用设置, so that 改键失败不会使截图入口失效。
4. As a Windows 用户, I want 重启后记住快捷键等设置, so that 不必重复配置。
5. As a Windows 用户, I want 自行开启开机启动且默认关闭, so that 可以控制软件何时常驻。
6. As a Windows 用户, I want 再次启动软件时唤起已有实例, so that 不会出现重复托盘图标及快捷键冲突。
7. As a 截图用户, I want 冻结触发时的屏幕画面, so that 可以稳定选择需要的内容。
8. As a 截图用户, I want 鼠标悬停自动选中整个窗口并单击确认, so that 可以快速截取窗口。
9. As a 截图用户, I want 自由框选、移动及调整选区并查看像素尺寸, so that 可以精确截取局部内容。
10. As a 多显示器用户, I want 截取鼠标所在显示器或跨屏手动框选, so that 不同桌面布局都能使用。
11. As a 多显示器用户, I want 在混合缩放和负坐标布局中仍准确对齐, so that 导出范围和标注不会错位。
12. As a 截图用户, I want 画笔、矩形、椭圆、箭头、文字和马赛克, so that 可以解释或遮挡图片内容。
13. As a 截图用户, I want 修改颜色、线宽和字号并输入中文, so that 标注清楚且符合需要。
14. As a 截图用户, I want 选择、移动、删除标注并修改原文字，拖动箭头两端及矩形、椭圆的控制点调整形状, so that 标错后可以修正。
15. As a 截图用户, I want 撤销和重做编辑, so that 可以试画而不必重新截图。
16. As a 截图用户, I want 默认确认后复制并贴图, so that 可以立即粘贴，也能在桌面参考。
17. As a 截图用户, I want 将完成动作改成仅复制或仅贴图, so that 可以适应不同使用习惯。
18. As a 截图用户, I want 保存成功后结束本次截图且仅保存, so that 保存不会额外改动剪贴板或新增贴图。
19. As a 截图用户, I want 取消保存或保存失败后继续编辑, so that 不会丢失当前工作。
20. As a 截图用户, I want 导出普通 PNG/JPG 并记住上次保存目录, so that 可以在其他软件直接使用文件。
21. As a 贴图用户, I want 多张贴图置顶并可拖动、缩放及调整透明度, so that 可以边操作边参考图片。
22. As a 贴图用户, I want 再次编辑原有标注并确认更新原贴图, so that 无需重新截图，也不会新增重复贴图。
23. As a 贴图用户, I want 取消再次编辑时恢复编辑前内容, so that 试改不会破坏原图。
24. As a 贴图用户, I want 再次编辑不自动复制, so that 不会覆盖刚复制的其他内容。
25. As a 贴图用户, I want 主动复制或保存当前贴图, so that 可以决定何时输出结果。
26. As a 贴图用户, I want 编辑中可导出草稿而继续编辑, so that 导出副本与更新原贴图互不替代。
27. As a 贴图用户, I want 缩放和透明度只影响展示, so that 导出仍使用原始像素尺寸与不透明内容。
28. As a 贴图用户, I want 新截图时临时隐藏已有贴图并在结束后恢复, so that 不会把旧贴图重复截进去。
29. As a Windows 用户, I want 关闭贴图即移除且重启不恢复, so that 软件不维护截图历史。
30. As a Windows 用户, I want 捕获、剪贴板或文件操作失败时保留可恢复的工作状态, so that 可重试且不会生成重复贴图。
31. As a 接收安装包的用户, I want 普通权限下离线安装且无需另装 .NET, so that 可以直接在其他电脑使用。
32. As a 接收安装包的用户, I want 升级保留设置、卸载保留主动导出的图片, so that 更新和移除软件不会影响个人文件。

## Implementation Decisions

### 平台与技术路线

- 产品名称暂用 ScreenshotTool，界面为简体中文。
- 使用 C# + WPF + .NET 10 LTS；Windows 桌面集成使用原生能力。
- 以 Windows 10 22H2 x64 与 Windows 11 x64 作为首版兼容性验收目标。
- Windows x64 自包含发布，使用 Inno Setup 制作当前用户离线安装 EXE；不请求管理员权限。
- 原始画面和独立标注在当前运行期间保留；导出时合成为普通图片，不保留独立可编辑标注，也不保存工程图层或恢复数据。

### 默认设置与输入

- 初始截图快捷键为 Ctrl+Alt+S；被占用时提示改键，托盘截图入口仍可用。修改失败保留旧快捷键。
- 开机启动默认关闭；默认完成动作为复制并贴图；默认图片格式为 PNG。
- 托盘图标左键单击打开已有设置界面；左键双击不触发截图。右键提供开始截图、设置、管理贴图和退出菜单，截图仍可通过全局快捷键或菜单触发。
- 一次只允许一个截图或贴图编辑会话，重复截图快捷键不创建并行会话。
- Enter 确认，Esc 取消，Ctrl+Z/Ctrl+Y 撤销重做，Ctrl+S 保存。文字输入框中 Enter 用于换行，不触发整个截图确认。

### 选区与显示

- 获取屏幕快照前，隐藏本软件的设置窗口、贴图管理窗口及已有贴图；关闭这些窗口的隐藏过渡并等待桌面刷新，避免把半透明淡出残影截入图片。
- “全屏”指鼠标所在显示器，手动框选允许跨屏。
- 窗口选取识别整个可见顶层窗口，不细分内部控件，也不重建被其他窗口遮挡的内容。
- 捕获以普通 SDR 桌面为基线；选区、标注和导出采用一致的实际像素对应关系。
- 必须支持混合显示缩放、负坐标屏幕布局和选区跨屏，不因缩放错位。
- 调整选区仅改变裁剪，不拉伸标注；超出选区部分不导出。
- 贴图的缩放、透明度仅影响显示，复制和导出不改变原始像素尺寸，也不应用贴图窗口透明度。

### 操作副作用

- 选中箭头后显示起点、终点两个控制点，拖动任一端调整长度与角度，另一端保持原位。
- 选中矩形或椭圆后显示边角控制点，拖动调整宽高；拖动图形主体仍可整体移动。
- 控制点调整适用于新截图和贴图再次编辑；一次完整拖动只产生一步撤销记录，重做可恢复调整结果。控制点只在编辑界面显示，不进入复制或导出图片。

| 操作 | 编辑状态 | 剪贴板 | 贴图 | 导出文件 |
| --- | --- | --- | --- | --- |
| 新截图完成：复制并贴图 | 结束 | 复制结果 | 新建一张 | 无 |
| 新截图完成：仅复制 | 结束 | 复制结果 | 不新建 | 无 |
| 新截图完成：仅贴图 | 结束 | 不改变 | 新建一张 | 无 |
| 新截图保存成功 | 结束 | 不改变 | 不新建 | 保存图片 |
| 新截图保存取消或失败 | 保持编辑 | 不改变 | 不新建 | 取消不写入；失败可重试 |
| 贴图编辑确认 | 结束 | 不改变 | 更新原贴图 | 无 |
| 贴图编辑取消 | 结束 | 不改变 | 原贴图恢复编辑前状态 | 无 |
| 贴图编辑中保存成功 | 保持编辑 | 不改变 | 原贴图不变 | 导出当前草稿 |
| 贴图窗口复制 | 不进入编辑 | 复制结果 | 不改变 | 无 |
| 贴图窗口保存 | 不进入编辑 | 不改变 | 不改变 | 保存图片 |

- 取消新截图不改变剪贴板、不创建贴图、不自动保存。
- 取消贴图编辑不删除之前主动导出的草稿文件。
- 开始截图前临时隐藏已有贴图，完成、取消及捕获失败后均恢复。
- 复制失败时保留当前编辑，允许重试，不能重复创建贴图。
- 捕获失败时返回可使用的托盘状态；不可写目录和占用冲突应给出可理解的反馈。
- 关闭贴图或正常退出不逐张提示保存；无历史和重启恢复。退出不主动清空系统剪贴板。

### 职责边界

- 截图工作流负责新截图与贴图编辑的状态及输出副作用；是行为测试的主要入口。
- 截图内容负责原图、独立标注、裁剪、编辑与撤销重做，给所有输出生成一致结果。
- 贴图管理负责当前运行期间的多张贴图及其编辑提交与取消。
- 桌面集成封装快捷键、显示器与捕获、剪贴板、托盘和置顶窗口。
- 设置与分发负责当前用户设置、单实例、开机启动、安装、升级和卸载。
- 具体捕获 API、类名和界面排布由实施计划决定，不扩展本文范围。

## Testing Decisions

- 当前仓库仅有配置与需求文档，没有既有产品或测试实现可复用。
- 主要测试入口为一次完整截图工作流：通过可控的剪贴板与文件输出适配器，验证用户操作后的编辑状态、贴图数量、图片内容和外部副作用，而非内部调用细节。
- 对选区到导出图片的坐标和像素结果、标注编辑、撤销重做与草稿隔离进行有代表性的内容验证。
- 真实捕获、快捷键、托盘、混合 DPI、置顶行为不能由纯逻辑测试代替，需在目标 Windows 桌面验证。
- 在未预装 .NET 的 Windows 10/11 x64 环境中，普通用户离线安装、启动、升级及卸载；确认设置保留、导出图片保留。
- 必测保存成功仅保存并结束、保存取消和失败继续编辑、贴图编辑取消回滚、确认不新增也不复制、草稿导出不提交原贴图。
- 必测混合缩放、负坐标、跨屏框选、中文输入 Enter 换行、快捷键占用、剪贴板暂不可用及重复按键。
- 必测捕获失败及所有退出路径恢复临时隐藏的贴图。
- 使用测试自身的前景/背景窗口做真实像素回归：隐藏前景并等待刷新后，快照必须显示背景；隐藏和刷新失败时不抓屏且释放当前编辑会话。
- 应验证图像和原生资源及时释放；关闭贴图与编辑会话后不继续持有对应截图内容，除非仍被其他打开的贴图使用。

## Out of Scope

- OCR、滚动长截图、录屏、云同步、账号系统和自动更新服务。
- 截图历史、重启恢复贴图、工程文件格式，以及从 PNG/JPG 恢复原标注。
- macOS、Linux、Windows 7/8、x86 和原生 ARM64 安装包。
- 窗口内部控件自动识别、后台窗口完整重建。
- HDR 色彩还原、受保护画面或安全桌面与普通桌面一致的捕获保证。
