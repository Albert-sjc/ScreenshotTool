# 截图工具需求访谈

本文件保留需求澄清过程和用户原始回答；需求已整体确认，实施以正式规格为准。

## 用户明确提出

- 仅面向 Windows 10/11。
- 可以自定义截图快捷键。
- 参考 QQ 截图的操作体验，框选后可以使用画笔、矩形框等标注工具。
- 可以保存截图。
- 截图完成后可以贴图置顶。
- 提供安装包，能够安装到其他电脑。

## 用户认可的初步基线

- 常驻系统托盘，提供设置和退出入口；开机启动可选。
- 快捷键支持占用检测、立即生效和重启记忆。
- 支持手动框选、调整与移动选区、显示像素尺寸、全屏和多显示器截图。
- 标注包括画笔、矩形、椭圆、箭头、文字、马赛克，可调整对应的颜色、线宽或字号。
- 编辑期间支持撤销、重做、选择和删除标注。
- 支持复制到剪贴板，以及保存为 PNG/JPG；记住上次保存目录。
- 默认完成动作建议为复制并贴图，也可配置为仅复制或仅贴图。
- 贴图支持置顶、拖动、缩放、透明度调整、关闭和多张并存。
- 再次截图时，默认临时隐藏已有贴图。
- 截图编辑使用 Enter 完成、Esc 取消、Ctrl+Z/Ctrl+Y 撤销与重做、Ctrl+S 保存。
- 安装包包含快捷方式和卸载入口，支持离线安装，升级保留设置。
- 第一版暂缓 OCR、滚动长截图、录屏和云同步。
- 以 Windows 10/11 x64 为初步交付目标；具体系统版本和混合缩放多显示器列入兼容性验收。

## 已确认的技术路线

- 使用 C# + WPF + .NET 10 LTS，自包含发布，并使用 Inno Setup 制作当前用户安装包。
- 用户于 2026-11-13 对整份需求设计及建议默认值回复“确认”。

## 第一轮已确认

1. 需要鼠标悬停自动识别整个窗口，点击即可选中；保留手动框选与全屏截图。
2. 贴图可以重新进入编辑，原有标注仍可单独修改，包括修改文字、移动矩形框和删除画笔笔迹。
3. 退出软件或重启电脑后，不恢复上次打开的贴图。

用户原始回答：`1需要，2需要，3不恢复`。

## 第二轮已确认

4. 保存的 PNG/JPG 是普通图片，不保留可单独修改的标注；可编辑标注仅用于当前运行期间仍打开的贴图。
5. 第一版不提供截图历史；关闭贴图即移除，需要留存时用户主动保存。
6. 贴图再次编辑完成后，只更新贴图，不自动复制到剪贴板；复制和保存由用户主动触发。

用户原始回答：`4不需要，5不需要，6不自动复制`。

## 第三轮已确认

7. 新截图编辑中保存成功后，立即结束本次截图，仅保存，不额外复制或贴图；取消保存时保留编辑状态。
8. 贴图再次编辑时，确认后更新原贴图，不新增贴图；取消后恢复编辑前状态。
9. 安装包仅为当前用户安装，不请求管理员权限。

用户原始回答：`7结束，8是，9当前用户`。

## 使用反馈：托盘左键行为

用户要求关闭界面后，左键点击托盘图标重新打开界面，而非进入截图。已按现有设置窗口实现；左键双击也不触发截图，右键菜单和截图快捷键保留。此项纳入 1.0.2。

## 使用反馈：截图前界面残影

用户提供了截图时设置窗口半透明残留的图片。旧实现隐藏后固定等待 100 毫秒，没有同步桌面合成。1.0.3 改为关闭本软件窗口的隐藏过渡、等待桌面刷新后抓屏，并补充真实窗口像素及失败恢复回归测试。

## 使用反馈：标注控制点（2026-11-16）

用户要求再次选中箭头时有两个激活点，可重新调整长度和角度，并追加椭圆、矩形框也需要调整。按现有标注编辑流程加入控制点：箭头两端分别可拖动，矩形和椭圆通过边角调整宽高，主体仍可整体移动；支持撤销重做及贴图再次编辑，控制点不进入图片输出。此项纳入 1.0.4。
