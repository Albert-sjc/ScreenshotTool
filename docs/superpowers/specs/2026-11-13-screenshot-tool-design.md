# 截图工具第一版需求与设计

日期：2026-11-13。

状态：已确认。用户于 2026-11-13 对本稿及建议默认值回复“确认”；九项访谈回答、默认交互与技术路线均纳入本版需求。

依据：用户的初始要求、认可的初步方案，以及三轮需求访谈。访谈记录见项目根目录下 `.scratch/screenshot-tool/requirements-notes.md`；领域词汇见 `CONTEXT.md`。

## 目标与范围

提供一款适用于 Windows 10/11 的桌面截图软件。用户可以自定义截图快捷键，框选或选择窗口，添加标注，复制或保存结果，并把截图作为可再次编辑的贴图置顶。

软件常驻系统托盘。目标用户在其他电脑上使用离线安装包安装后即可使用，无需配置开发环境或另行安装 .NET。参考 QQ 截图的操作习惯，第一版覆盖下述明确列出的功能。

## 已确认的功能需求

### 启动、托盘与快捷键

- 托盘菜单提供开始截图、设置、管理贴图和退出。
- 左键点击托盘图标打开设置界面；左键双击不再触发截图。截图通过快捷键或右键菜单中的“开始截图”触发。
- 设置页允许录入截图组合键；修改后立即生效，重启后保留。
- 验证快捷键是否可用，检测到占用时告知用户重新选择。
- 支持可选的开机启动。
- 程序后台运行时仍可通过截图快捷键唤起截图。

### 选区与屏幕画面

- 进入截图时冻结当前屏幕画面，用户可以手动拖动框选。
- 冻结前完整隐藏本软件界面，禁用本软件窗口的隐藏过渡并等待桌面刷新，避免设置、贴图管理和已有贴图出现半透明残影。
- 鼠标悬停时自动识别整个窗口，单击即可选中；拖动可切换为手动框选。
- 选区可移动和调整大小，显示实际像素尺寸。
- 提供全屏截图，并支持多显示器场景。
- 开始新的截图时，默认临时隐藏已有贴图；结束或取消后恢复它们。

### 标注与首次截图编辑

- 提供画笔、矩形、椭圆、箭头、文字、马赛克。
- 可调整相应工具的颜色、线宽、字号；支持中文文字输入。
- 支持撤销、重做、选择、移动和删除标注；对文字可以修改内容。
- 选中箭头显示首尾两个控制点，拖动任一端调整长度和角度；矩形与椭圆显示边角控制点，可拖动改变宽高。拖动主体仍整体移动，一次控制点拖动只记一步撤销；贴图再次编辑同样适用，控制点不进入输出图片。
- 新截图的完成动作可配置为仅复制、仅贴图、复制并贴图；默认复制并贴图。
- 截图编辑完成使用 Enter 或完成按钮；Esc 取消本次截图；Ctrl+Z/Ctrl+Y 撤销与重做；Ctrl+S 保存。

### 保存与复制

- 可以复制截图到系统剪贴板，并在其他应用中粘贴为图片。
- 保存为 PNG 或 JPG，记住上次成功保存的目录。
- 新截图编辑中保存成功，结束本次截图；该动作仅保存，不额外复制或生成贴图。
- 取消保存时保留当前编辑状态。
- 导出图片将截图和标注合成为普通图片，不保留独立可编辑标注。
- 保存后的文件再次打开时，不要求修改原来的独立标注；第一版不提供可编辑工程文件格式。

### 贴图及再次编辑

- 贴图独立显示在普通桌面窗口上方，支持拖动、缩放、透明度调整和关闭。
- 支持多张贴图同时打开。
- 贴图可以再次进入编辑，原有标注仍可单独修改，包括修改文字、移动矩形框和删除画笔笔迹。
- 重新编辑确认后更新原贴图，不新增贴图；取消则恢复编辑前的状态。
- 再次编辑完成后不自动复制，不受新截图“完成动作”设置影响。
- 用户可以主动复制或保存当前贴图。
- 第一版不提供截图历史；关闭贴图即移除，需要留存时用户主动保存。
- 退出软件或重启电脑后，不恢复上次打开的贴图。

### 安装与升级

- 仅面向 Windows 10/11。
- 仅为当前登录用户安装，不请求管理员权限。
- 提供开始菜单入口、可选的桌面快捷方式以及卸载入口。
- 安装和使用核心功能支持离线；升级保留快捷键及其他设置。

## 已确认的默认值

以下为设计者提出、经用户整体确认的具体默认行为。

### 产品与设置

- 名称暂用 ScreenshotTool，第一版提供简体中文界面。
- 初始截图快捷键为 Ctrl+Alt+S；若被占用，保留托盘截图入口并提示设置其他组合键。
- 修改快捷键失败时保留旧快捷键，不把不可用的新值当作设置成功。
- 开机启动默认关闭。
- 默认新截图完成动作为复制并贴图；默认保存格式为 PNG。
- 软件按单实例运行，再次启动只唤起已有实例，避免重复注册快捷键。

### 捕获与显示

- 以 Windows 10 22H2 x64 与 Windows 11 x64 作为首版兼容性验收目标；不把系统运行能力视为已经验证的结论。
- “全屏”默认指鼠标所在显示器；手动框选允许跨显示器。
- 自动窗口选取以整个可见的顶层窗口为范围，不自动细分识别窗口内部按钮、列表等控件，也不恢复被其他窗口遮住的内容。
- 以普通 SDR 桌面画面作为首版捕获验收基线；HDR 色彩还原、受保护画面及安全桌面不承诺与普通桌面相同的捕获行为。
- 支持单屏和多屏、125%/150%/200% 等混合缩放、负坐标显示器布局。选区、标注和导出图片应对齐，不因显示缩放产生位置偏差。
- 已有标注随截图内容保持位置关系；调整选区只改变裁剪范围，不拉伸标注，超出选区的部分不导出。
- 贴图缩放和透明度仅改变桌面展示；复制和保存使用原始截图像素尺寸与不透明的图片内容。

### 贴图编辑与退出

- 再次编辑贴图时显示当前图片与可编辑标注，确认后提交到原贴图，取消则丢弃本次修改。
- 若在贴图再次编辑中使用 Ctrl+S，导出当前编辑草稿并保持编辑界面；随后确认才更新原贴图。取消编辑不删除已主动导出的文件。此行为与新截图“保存后结束”有明确区分。
- 文字输入框获得焦点时，Enter 用于换行；结束文字输入后 Enter 才执行截图或贴图编辑确认。工具栏始终提供确认和取消入口。
- 截图或贴图编辑期间重复按全局截图快捷键，不创建并行编辑会话。
- 关闭贴图或正常退出时直接关闭，不额外弹出逐张保存提示；用户事先主动保存需要留存的图片。
- 不将截图及可编辑标注作为历史或恢复数据持久化；设置独立保留。退出软件不主动清空用户的系统剪贴板。

### 出错时的行为

- 截图捕获失败时返回可使用的托盘状态，并恢复临时隐藏的已有贴图。
- 保存失败时保留编辑状态和标注，给出可理解的原因，允许重试。
- 新截图的完成动作包含复制而复制失败时，保留编辑界面，允许重试；重试不能重复生成贴图。
- 不可写的保存目录、被占用的快捷键以及实例冲突，不应导致软件退出或丢失当前可编辑内容。
- 升级保留当前用户的设置；卸载不删除用户主动导出的图片，设置清理策略由安装实现说明清楚。

## 实现方式比较与选择

用户已随本稿整体确认 C# + WPF + .NET 10 LTS 路线。保留备选路线的比较，说明取舍。

| 路线 | 适用性与取舍 |
| --- | --- |
| C# + WPF + .NET 10 LTS | 已选择。聚焦 Windows 桌面窗口、输入与图形交互，使用 Windows 原生能力注册全局快捷键和捕获桌面。通过自包含发布携带运行时。 |
| C++ + Qt | 未选择。适合有明确跨平台计划的产品；本项目当前只需要 Windows，暂不承担额外的跨平台捕获与输入适配工作。 |

安装包使用 Inno Setup，把 Windows x64 的自包含发布结果封装为单个安装 EXE，采用当前用户安装模式。

构建前需对所选捕获方式及 .NET 版本在目标 Windows 10/11 系统上的实际兼容性进行验证。自包含发布解决运行时分发问题，不替代操作系统兼容性测试。

技术依据：

- [WPF 官方说明](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/overview/)：WPF 是 Windows 桌面 UI 框架。
- [.NET 支持策略](https://dotnet.microsoft.com/en-us/platform/support/policy)：.NET 10 为 LTS 版本。
- [.NET 自包含发布](https://learn.microsoft.com/en-us/dotnet/core/deploying/)：发布结果携带运行时，目标电脑无需预装 .NET。
- [Windows 全局快捷键](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-registerhotkey)：使用原生快捷键注册及失败反馈。
- [Inno Setup](https://jrsoftware.org/isinfo.php) 及[当前用户安装权限设置](https://jrsoftware.org/inno-setup/documentation/topic_setup_privilegesrequired.htm)：支持安装 EXE、卸载和非管理员安装。
- [Qt 支持平台](https://doc.qt.io/qt-6/supported-platforms.html)：备选跨平台路线。

## 模块职责

- 截图会话：组织屏幕快照、选区、标注编辑、确认与取消，控制一次仅有一个编辑会话。
- 截图内容：持有原始画面及独立标注，执行撤销重做，生成供复制、导出及贴图展示使用的一致结果。
- 贴图管理：维护当前打开的贴图及其展示状态，处理编辑提交与取消，关闭时释放对应内容。
- Windows 桌面集成：封装快捷键、显示器与坐标、捕获、剪贴板、窗口置顶和托盘交互。
- 设置与分发：持久化当前用户设置，完成自包含发布、安装、升级和卸载。

标注在当前会话及贴图中保持可编辑，PNG/JPG 仅输出合成后的普通图片。安装运行不依赖开发环境、账号或远程服务。

具体类名、目录、图标、配色、工具栏排布、马赛克粒度、缩放步长、快捷键录入控件，以及捕获 API 的选择由实现阶段决定；这些选择应满足本文的操作结果和验收要求。

## 验收场景

1. 在没有预装 .NET 的目标电脑上，以普通用户离线安装、启动、截图、复制、保存、贴图，并卸载。
2. 修改快捷键并重启软件，设置仍生效；设置被占用的组合键时，原有可用快捷键保持可用。
3. 悬停自动选中整个窗口，拖动改为手动框选；调整选区、移动选区和全屏操作均符合默认定义。
4. 在混合缩放、跨屏和负坐标布局下，导出范围、标注位置和实际像素尺寸一致。
5. 六种标注工具可用；中文文字可输入，已有标注可修改，撤销与重做结果正确。
6. 新截图按默认动作完成，只复制一次并创建一张贴图；改成仅复制或仅贴图后无另一种副作用。
7. 新截图保存成功即结束，没有额外复制或贴图；取消保存或保存失败后仍可继续编辑。
8. 贴图再次编辑确认后更新原贴图，数量不增加，也不覆盖剪贴板；取消编辑后画面及原有标注不变。
9. 导出 PNG/JPG 的内容与编辑结果一致，文件不包含独立可编辑标注；贴图缩放或透明度不改变导出尺寸与内容。
10. 关闭贴图后没有历史可找回；退出再启动不恢复贴图，但快捷键等设置保留。
11. 开始截图时已有贴图被临时隐藏；完成、取消或捕获失败后都能恢复。
12. 重复按快捷键、剪贴板暂时不可用、不可写目录等情况不会重复生成贴图或丢失当前编辑内容。

自动化验证以选区与导出尺寸、标注编辑和撤销重做、操作副作用、设置保持等可观察行为为主；真实全局快捷键、混合 DPI 桌面捕获、窗口置顶及安装行为通过目标系统上的集成验证补足。

## 第一版范围外

- OCR、滚动长截图、录屏、云同步、账号系统和自动更新服务。
- 截图历史、重启恢复贴图、可编辑工程文件，以及从 PNG/JPG 恢复独立标注。
- macOS、Linux、Windows 7/8、x86 与原生 ARM64 安装包。
- 自动识别窗口内部控件、后台窗口完整重建及对特殊受保护画面的捕获保证。
